# 정상 학습 모델의 특징 선택 실험

기존 17개 특징 중 소수의 조합을 선택해 KI04 미탐을 줄이는 개발 실험입니다.
정상 데이터만으로 Isolation Forest를 학습하는 구조는 유지합니다. 손상 라벨은 특징
선택과 개발 성능 비교에 사용하며, 모델 학습이나 경고 경계 설정에는 넣지 않습니다.

## 실행

먼저 `run_feature_experiment.py`로 특징을 추출한 뒤 실행합니다.

```powershell
.\.venv\Scripts\python.exe run_feature_selection.py
```

기본적으로 가장 최근에 완료한 특징 비교 실험을 사용합니다. 입력을 명시하려면:

```powershell
.\.venv\Scripts\python.exe run_feature_selection.py --source data/paderborn/derived/feature_experiments/20261108-002145-609238
```

새 결과는 `data/paderborn/derived/feature_selection/<실행시각>/`에 저장합니다.
`--output <새 폴더>`로 위치를 지정할 수도 있습니다. 기존 폴더는 덮어쓰지 않습니다.
기본 모델이나 대시보드에는 자동 반영하지 않습니다.

### 대시보드 연결

선택 실험을 마친 모델은 다음 별도 명령으로 대시보드에 적용합니다.

```powershell
.\.venv\Scripts\python.exe activate_selected_model.py
```

현재 프로젝트에는 이 과정을 실행해 선택 특징 4개의 개선 모델을 연결하였다.
선택 모델과 경고 기준값을 그대로 가져오며 재학습하지 않는다. 개발 기록 80개를 새 입력
경로로 다시 분석해 기존 실험과 점수·예측이 같은지 확인한 뒤 활성화한다. 최종 평가 기록은
읽지 않는다. 대시보드는 개선 모델만 사용하고 기존 모델은 비교 근거로 파일에 보존한다.

## 비교 절차

1. 이전 특징 추출의 설정·코드 해시·원본 목록과 현재 파일이 일치하는지 검사합니다.
2. 순위 기준·상관 기준·후보 수 상한·시드를 `analysis_plan.json`에 먼저 저장합니다.
3. 기록별 특징 중앙값으로 정상 K003·K004와 손상 KA04·KI04의 분포를 확인합니다.
4. 특징 순위와 후보 조합을 `candidates.json`에 고정한 뒤 모델을 비교합니다.
5. 기본 시드 42로 후보를 선택하고, 대조군과 선택 후보만 시드 5개로 점검합니다.
6. 모든 지표·예측·모델·그래프를 새 실험 폴더에 저장합니다.

학습은 정상 K001·K002 40개 기록, 경계 설정은 정상 K003·K004 40개 기록으로 수행합니다.
같은 정상 기록과 KA04·KI04 40개 기록으로 개발 지표를 계산합니다. 최종 평가용
K005·K006·KA15·KI14의 원본 신호와 특징에는 접근하지 않습니다.

창 길이·시간축 처리·품질 제외는 [앞선 특징 비교 실험](feature-experiment.md)과 같습니다.
제외한 28개 창을 모든 후보에 동일하게 적용하며, 제외 창을 건너뛰어 경고를 연결하지
않습니다. 모델 입력은 기록 중앙값이 아니라 사용 가능한 각 시간 창의 특징입니다.

### 특징 순위와 실험 상한

각 특징에서 정상/손상 베어링 쌍 네 개의 기록 중앙값 AUC를 계산합니다.
손상이 정상 두 베어링보다 모두 높은 방향, 또는 모두 낮은 방향으로 분리되는지 봅니다.
가장 구분하기 어려운 쌍의 결과를 사용하므로 KA04만 잘 구분하는 특징의 순위를 제한합니다.
손상이 정상 두 군집 사이에 끼어 있으면 공통 방향 구분 지표가 낮아집니다.
이는 이번 실험의 후보 순위 기준이며 범용적인 이상 탐지 특징 선택법은 아닙니다.

실험은 다음 최대 23개 조합으로 제한합니다.

- 기존 특징 4개와 이전 주파수 후보 11개: 대조군 2개
- 기존 특징 17개를 각각 단독 사용: 17개
- 순위 상위 특징 2·3·4·6개 조합: 최대 4개

조합을 만들 때 기록 중앙값의 절대 Spearman 상관이 0.90 이상이면 순위가 낮은 특징을
중복 정보로 보고 조합에서 제외합니다. 단일 특징 실험에서는 그대로 비교합니다.
후보 성능을 본 뒤 새로운 조합을 추가하거나 주파수 대역·경고 경계를 변경하지 않습니다.

### 후보 선택과 민감도 점검

Isolation Forest는 트리 200개·시드 42로 고정합니다. 정상 tuning 기록 점수의
95백분위수와 연속 3개 창 초과 규칙을 모든 조합에 똑같이 적용합니다. 특징 조합에 따라
점수 분포와 경계의 숫자는 달라지며, 숫자를 직접 비교하거나 임의로 낮추지 않습니다.

정상 오경보가 1/40개 이하이면서 대조군보다 늘지 않고 KA04를 20/20개 탐지하는 후보 중,
전체 손상 탐지 수가 가장 높은 조합을 선택합니다. 동률이면 오경보와 특징 수가 적은
조합을 우선합니다. 이전 주파수 후보의 KI04 3/20개보다 개선되어야 새 추천으로 표시합니다.

선택을 마친 뒤 시드 7·19·42·73·101에서 결과를 점검합니다. 가장 좋은 시드를 다시 고르거나
안정성 점검 결과로 다른 특징 조합을 추가하지 않습니다. 이는 같은 데이터에서의 난수
민감도 점검이며 독립 검증이나 성능 신뢰구간은 아닙니다.

## 개발 결과

시드 42의 Isolation Forest 결과입니다.

| 특징 조합 | 특징 수 | 정상 오경보 | KA04 탐지 | KI04 탐지 | 전체 손상 미탐률 |
|---|---:|---:|---:|---:|---:|
| 기존 특징 | 4 | 1/40 | 20/20 | 0/20 | 50.0% |
| 이전 주파수 추가 | 11 | 1/40 | 20/20 | 3/20 | 42.5% |
| 순위 조합 2개 | 2 | 1/40 | 20/20 | 12/20 | 20.0% |
| 순위 조합 3개 | 3 | 1/40 | 20/20 | 14/20 | 15.0% |
| **순위 조합 4개** | **4** | **1/40** | **20/20** | **18/20** | **5.0%** |
| 순위 조합 6개 | 6 | 1/40 | 20/20 | 13/20 | 17.5% |

선택된 네 특징은 다음과 같습니다.

| 코드 이름 | 의미 |
|---|---|
| `power_ratio_0_1000` | 전체 진동 스펙트럼 에너지 대비 0–1 kHz 에너지 비율 |
| `power_ratio_12000_16000` | 전체 에너지 대비 12–16 kHz 에너지 비율 |
| `envelope_peak_fraction` | 엔벨로프 20–1000 Hz 대역에서 가장 큰 주파수 빈의 에너지 비율 |
| `kurtosis_pearson` | 원본 진동 창의 평균을 제거한 Pearson 첨도 |

주파수 중심값은 순위가 높았지만 다른 선택 특징과 상관이 높아 조합에서는 제외됐습니다.
추가한 모든 특징을 사용하는 것보다 정보가 다른 네 특징을 선택한 결과가 더 좋았습니다.
이 관측만으로 각 특징의 인과적 기여나 손상 원인을 확정할 수는 없습니다.

기본 시드에서 KI04의 9번·13번 기록을 놓쳤고 정상 K004의 2번 기록에 오경보가 발생했습니다.
선택된 조합의 시드별 결과는 다음과 같습니다.

| 시드 | 정상 오경보 | KA04 탐지 | KI04 탐지 |
|---:|---:|---:|---:|
| 7 | 1/40 | 20/20 | 16/20 |
| 19 | 1/40 | 20/20 | 17/20 |
| 42 | 1/40 | 20/20 | 18/20 |
| 73 | 1/40 | 20/20 | 14/20 |
| 101 | 1/40 | 20/20 | 19/20 |

비교 대상으로 함께 확인한 기존 특징과 이전 주파수 후보도 일부 시드에서 탐지가 크게
줄었습니다. 선택 후보가 이번 민감도 점검에서는 더 일관됐지만, 새 베어링에서도 안정적이라고
판단하려면 별도의 평가가 필요합니다.

## 출력과 해석의 한계

- `selection.md`, `selection.json`: 모든 후보 지표·기록별 점수·추천·시드 점검 결과
- `feature_distributions.png/.pdf`: 특징 17개의 기록별 중앙값 분포
- `selected_distributions.png/.pdf`: 선택 특징의 정상·손상 분포
- `normal_vs_ki04.png/.pdf`: 선택 특징에서 정상 K003·K004와 KI04를 확대 비교
- `record_feature_medians.csv`: 그래프와 순위에 사용한 기록별 요약값
- `selection_models.joblib`: 기존 모델과 별도로 저장한 후보 모델

손상 라벨로 특징을 선택했으므로 전체 파이프라인을 순수한 비지도 선택이라고 부를 수는
없습니다. **개발 손상 라벨을 참고해 특징을 선택하고, 정상만으로 이상 탐지 모델을 학습한
방식**입니다. 같은 개발 기록을 반복해서 비교한 결과이므로 최종 성능보다 낙관적일 수 있습니다.
특히 개발용 정상 기록은 경고 경계를 설정하는 데도 사용했으므로 오경보 2.5%가 새로운 정상
베어링에서 재현된다고 보장하지 않습니다.

20개 기록은 같은 베어링의 반복 측정이며 독립 손상 베어링 20개가 아닙니다. 특징 추출의
시간축 보간·품질 제외·단위 미확인 한계도 남아 있습니다. 최종 평가용 80개는 보존했고,
이 실험만으로 산업 현장 성능이나 다른 장비의 탐지 성능을 주장하지 않습니다.

특징 선택 개념 참고: [scikit-learn 공식 문서](https://scikit-learn.org/stable/modules/feature_selection.html).
