# 주파수·엔벨로프 특징 비교 실험

기존 모델을 보존한 채, KI04 미탐을 줄일 수 있는지 비교하는 개발용 실험입니다.
실험 결과를 대시보드나 기본 분석 설정에 자동 반영하지 않습니다.

## 실행과 출력

프로젝트 루트에서 실행합니다. 기존 `prepare`로 데이터가 준비되어 있어야 합니다.

```powershell
.\.venv\Scripts\python.exe run_feature_experiment.py
```

실행마다 `data/paderborn/derived/feature_experiments/<실행시각>/`을 새로 생성합니다.
`--output <새 폴더>`로 출력 위치를 지정할 수도 있습니다. 기존 폴더는 덮어쓰지 않습니다.

| 파일 | 내용 |
|---|---|
| `protocol.json` | 계산 전에 고정한 특징 조합·처리 조건·선택 규칙, 원본 해시, 코드 해시, 패키지 버전 |
| `comparison.md` | 기존 저장 결과, 실험 대조군, 후보들의 성능 비교 |
| `comparison.json` | 경계값, 기록별 점수·예측, 베어링별 지표, 특징 분포, 제외 창 |
| `features/*.json` | 개발용 기록 120개의 시간·주파수·엔벨로프 특징과 품질 정보 |
| `experiment_models.joblib` | 네 조합별 통계 모델·Isolation Forest·경계값. 기본 모델과 별도 저장 |

## 비교 조건

- 정상 K001·K002의 40개 기록으로만 학습합니다.
- 정상 K003·K004의 40개 기록으로만 경고 경계를 설정합니다.
- K003·K004·KA04·KI04의 80개 개발 기록에서 성능을 비교합니다.
- 최종 평가 베어링 K005·K006·KA15·KI14의 신호는 읽지 않습니다.
- Isolation Forest는 트리 200개·시드 42, 경계는 정상 기록 점수의 95백분위수입니다.
- 각 연속 3개 창의 최솟값 중 최댓값을 기록 점수로 사용합니다. 경계를 엄격히 초과하면 경고합니다.
- 후보 선택에는 개발 손상 라벨을 사용합니다. 이는 정상만으로 모델을 학습하는 것과 구분됩니다.
- 오경보가 대조군보다 늘지 않고, KA04 탐지가 줄지 않으며, KI04 탐지가 늘어야 추천합니다.
  여러 후보가 만족하면 전체 손상 탐지 수, 오경보 수, 특징 수 순서로 선택합니다.

개발 기록은 80개지만 독립 베어링은 4개입니다. 기록을 무작위로 나눠 독립 검증처럼
취급하지 않습니다. 이 개발 결과로 새로운 장비나 손상에 대한 성능을 보장할 수 없습니다.

## 추가 특징과 시간축 처리

기존 4개 특징은 평균을 제거한 RMS·Pearson 첨도·최대최소 차이·파고율입니다.

주파수 후보는 기존 특징에 다음 7개를 추가합니다.

- 전체 스펙트럼 에너지 대비 0–1, 1–3, 3–6, 6–12, 12–16 kHz 대역 에너지 비율
- 주파수 중심값
- 정규화 스펙트럼 엔트로피

엔벨로프 후보는 기존 특징에 다음 6개를 추가합니다.

- 2–12 kHz 대역 통과 신호의 Hilbert 절댓값에서 계산한 변동계수와 첨도
- 엔벨로프의 20–1000 Hz 에너지 대비 20–200, 200–500, 500–1000 Hz 에너지 비율
- 같은 엔벨로프 대역에서 가장 큰 주파수 빈의 에너지 비율

결합 후보는 위 두 종류를 모두 추가합니다. 이 대역은 첫 비교를 위한 고정 후보이며,
특정 베어링의 결함 주파수나 손상 위치를 뜻하지 않습니다.

원본의 시각이 완전히 일정하지 않으므로 실제 시간축으로 창을 나눈 뒤, 주파수 계산에만
64 kHz 선형 보간을 적용합니다. 시간 특징은 원본 신호에서 계산한 값을 유지합니다.
Welch 계산은 Hann 창, 최대 8192샘플, 50% 겹침, 평균 제거를 사용합니다.
엔벨로프에는 4차 Butterworth 대역 통과와 반사 패딩을 사용합니다.

다음 창은 모든 후보에서 동일하게 제외합니다.

- 인접 시각 간격이 명목 64 kHz 간격의 4배를 초과하는 창
- 창 주변의 유효 샘플링 속도가 64 kHz에서 5% 넘게 벗어나는 창
- 계산에 필요한 샘플이 부족하거나 기본 특징이 정의되지 않는 창

제외한 창 양쪽의 점수를 연결해 연속 경고로 만들지 않습니다. 남은 연속 창이 부족한
기록은 분석 불가로 집계하며 정상으로 처리하지 않습니다. 일부 창만 제외된 기록의 지표는
사용 가능한 구간에서의 결과입니다. 보간은 누락 신호를 복원하거나 시간축의 물리적 정확성을
검증하지 않으므로, 현장 적용 전에는 수집 장치의 시간축과 단위부터 확인해야 합니다.

계산 정의: [SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html),
[SciPy Hilbert](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.hilbert.html).

## 첫 비교 결과

같은 품질 제외 조건을 적용한 실험에서 Isolation Forest 결과는 다음과 같습니다.

| 조합 | 특징 수 | 정상 오경보 | KA04 탐지 | KI04 탐지 | 손상 미탐률 |
|---|---:|---:|---:|---:|---:|
| 기존 특징 대조군 | 4 | 1/40 | 20/20 | 0/20 | 50.0% |
| 주파수 추가 | 11 | 1/40 | 20/20 | 3/20 | 42.5% |
| 엔벨로프 추가 | 10 | 1/40 | 19/20 | 2/20 | 47.5% |
| 두 종류 모두 추가 | 17 | 1/40 | 14/20 | 3/20 | 57.5% |

총 3720개 창 중 28개가 제외되었습니다. 시간 공백으로 12개, 국소 샘플링 속도 조건으로
16개가 제외되었고, 분석 불가 기록은 없었습니다. 학습 1238개 창과 개발 평가 2454개 창을
사용했습니다. 평가 단위는 창이 아니라 기록입니다.

기존에 저장된 모델과 실험 대조군은 구분해야 합니다. 품질 제외 후 재학습한 대조군의
통계 방식은 KA04 탐지가 13/20에서 1/20으로 변했습니다. 중앙값·MAD와 정상 경계가 바뀌었기
때문이며, 통계 방식의 결과가 정상 기준 구성에 민감함을 보여 줍니다. Isolation Forest의
대조군 탐지 수는 기존 저장 결과와 같았습니다. 새 특징의 효과는 같은 품질 조건의 대조군과
비교하며, 기존 모델은 그대로 보존합니다.

현재 선택 규칙에서는 주파수 추가 후보가 적합하지만, KI04의 17개 기록은 여전히 놓칩니다.
정상 K004와 KI04의 여러 새 특징 분포도 겹칩니다. 예를 들어 기록별 중앙값의 10–90백분위
범위에서 3–6 kHz 에너지 비율은 K004가 약 0.217–0.284, KI04가 0.231–0.305로 겹쳤습니다.
특징별 분포는 모델의 특징 기여도나 손상 원인을 뜻하지 않습니다.

이 결과는 **제한적인 개선**이며 문제 해결 완료로 해석하지 않습니다. 추가 특징 선택이나
정상 기준 구성 변경은 별도 실험으로 비교해야 합니다. 현재 후보를 기본 프로그램에 적용하거나
최종 평가를 실행하는 작업은 포함하지 않았습니다.
